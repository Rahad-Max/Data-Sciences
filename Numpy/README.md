# NumPy Fundamentals & Practice

A hands-on repository documenting core concepts, array manipulations, and practical exercises in **NumPy**—the foundational library for numerical computing and machine learning in Python.

---

## 📌 Repository Overview

This repository tracks my learning progression through NumPy basics, moving from core array creation to multidimensional indexing, slicing, and vectorized operations.

### Key Topics Covered

* **Array Creation & Attributes:** `np.array()`, `np.zeros()`, `np.ones()`, `np.arange()`, `np.linspace()`, `.shape`, `.ndim`, `.dtype`
* **Indexing & Slicing:** 1D, 2D, and multi-dimensional slicing (`arr[row, col]`, step strides, negative indexing)
* **Mathematical & Vectorized Operations:** Element-wise arithmetic, universal functions (`np.sin`, `np.exp`, etc.), aggregate methods (`sum`, `mean`, `max`, `std`)
* **Array Reshaping & Manipulation:** `.reshape()`, `.flatten()`, `np.vstack()`, `np.hstack()`
* **Boolean Masking & Filtering:** Conditional indexing (e.g., `arr[arr > 5]`) and logical filters (`np.where`)
